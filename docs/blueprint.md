# **App Name**: SociVerse

## Core Features:

- User Authentication: Secure user registration and login using email and password.
- Home Feed: Display posts from users and friends in a reverse chronological order.
- Post Creation: Allow users to upload photos with captions.
- Like and Comment: Enable users to like posts and leave comments.
- Story Carousel: Display user stories in a carousel at the top of the feed.
- Search Functionality: Allow users to search for other users, hashtags or trending content.
- Trending hashtags: Suggest trending hashtags to be included in posts using AI

## Style Guidelines:

- Primary color: Light blue (#89CFF0) for a clean, trustworthy social feel.
- Background color: Very light cyan (#E0FFFF) to maintain a light, airy interface.
- Accent color: Light violet (#B19CD9) used for gradient accents.
- Body and headline font: 'PT Sans', a humanist sans-serif suitable for headlines or body text.
- Use clean, minimalist icons for navigation and actions.
- Modern layout inspired by Instagram and Facebook.
- Smooth transitions and animations for UI elements.
